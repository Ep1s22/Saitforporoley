Описание
SHIFR — это -сайь, предназначенный для генераци надежных паролей и для их сохранения, а вот сылка на сайт http://192.168.1.15:5500/login

Установка и запуск
Требования: Убедитесь, что у вас установлены следующие зависимости: -Python 3.8+ -Flask

Настройка
1.Создайте проект : -Скопируйте репозиторий или создайте новый проект. 2.Установите зависимости : pip install Flask, все HTML страницы должны быть в папке templetes

Запуск
Для запуска выполните следующую команду: app.py run, и перейдите по ссылке которая высветиться в командной строке.

Функционал
Генерация паролей, возможность выбора сколько будет символов, так же есть возможность настраивать символы, цифры и буквы в пароле.


Пример использования
Зарегестриуйтесь, потом войдите сгенирируйте пороль, используйте его по вашим нуждам можно создать пароль в стим, в epic games, Dota 2, Вконтате, однокласниках, WATTSap, Viber, SKIPE и можете уходить с сайта.
